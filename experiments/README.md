# Archived explorations

Early experiments and manual checks have been preserved, rather than deleted. They are intentionally outside the main delivery pipeline.

- `legacy/`: initial data reading, image plotting, database and exploration scripts. These scripts may depend on manual paths or external data; check before reusing.
- `diagnostics/`: manual validation and ranking scripts retained to support continued investigation.

Use the supported `python -m scripts.run_pipeline` command for the hackathon delivery. Archived scripts are not guaranteed to run in isolation.
